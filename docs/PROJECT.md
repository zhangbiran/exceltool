# 项目目标与范围

## 目标

ExcelTool 为人和 AI Agent 提供确定、可脚本化的 Excel CLI，避免调用者为每次
局部查看或修改临时编写脚本。

## 首版范围

- `.xls`、`.xlsx` 单工作簿局部查看，覆盖 sheet 和范围选择。
- 按每个 sheet 的有效区域查看最后 N 行，并可同时限制列范围。
- 查询一个或全部 sheet 的有效范围、有效行列数和最后行列。
- 可回写的纯二维 JSON 查看，以及带范围元数据的完整 JSON。
- 可选查看单元格的 Western/Asian/Complex 字体槽与字号。
- 从位置参数、stdin 或 JSON 文件批量写入二维数组。
- 通过统一二维 JSON 写入单格或矩阵，支持字符串、数字、布尔值和公式。
- 通过范围命令清空单格或矩形并设置字体字号，未指定的样式属性保持不变。
- 写入或替换单元格批注，并在保存重开后验证批注和单元格内容。
- 设置字体前精确检查系统解析结果，保存后报告实际字体槽。
- 范围字体字号、范围内容清空和可选硬样式清除。
- 列出、查询信息、新增、删除、重命名和复制 sheet。
- 插入、删除、复制并插入行。
- 插入、删除、复制并插入列；列复制包含值、公式、样式和列宽。
- 显式按内容自适应列宽，并施加可配置的最大宽度（默认 60 mm）。
- 按工作簿、sheet 和范围查找显示值或公式，与 view 共用行、列、矩形、末尾及
  正方区域选择，支持大小写、结果上限及使用相同范围规则的 Python 正则搜索。
- 单工作簿、多 sheet、顺序执行的 JSON Patch v1；统一保存、重开验证和原子发布。
- 所有编辑默认执行全工作簿最终公式的保存前后守恒；非结构操作额外保护声明范围外
  的原始公式。
- 可选 SHA256 输入前置条件和就地发布前复核，避免覆盖编辑期间更新的原文件。
- 成功和失败 JSON 明确报告公式检查计数、意外变化及输入 SHA256。
- JSON 结果、稳定退出码、安全输出和写后重读验证。
- `--out` 仅同格式另存，不承担格式转换。
- Linux 与 Windows 原生环境使用同一命令语义；平台差异只限于 LibreOffice 启动、
  UNO、命令锁、字体发现、临时资源清理和启动入口。

## 原则

- 编辑默认修改输入文件；仅在明确另存时使用 `--out`。
- 工具不隐式创建备份；调用者按任务风险在修改前显式决定是否复制备份。
- 修改始终在临时副本完成并重开验证；失败不发布半成品。
- 公式保护默认启用且不能静默关闭；结构操作只豁免操作阶段的坐标变化，不豁免
  保存重开后的公式守恒。
- 不静默转换工作簿格式，不执行宏。
- `.xls` 与 `.xlsx` 使用相同命令；格式自身限制以明确错误返回。
- 一次命令只处理一个工作簿；多文件任务由调用者明确枚举后逐个执行。
- 全部工作簿命令通过当前操作系统用户的全局锁自动串行；调用方仍按顺序执行，不用
  并发或重试换取吞吐，也不绕过命令锁。帮助、版本和字体环境检查不占用该锁。
- 不要求二进制字节一致，但目标操作和关键未修改数据必须逻辑一致。

## 首版非目标

- GUI、图表、数据透视表和宏编辑。
- 跨工作簿复制行或列。
- 隐式写后自适应列宽、固定列宽、隐藏列、合并单元格和正则替换。
- 字符级富文本、全部 Excel 样式属性和复杂公式重算保证。
- 分布式服务或远程文件访问。
- 跨工作簿 patch、条件分支、变量引用和通用脚本语言。

## 验收

- `.xls` 与 `.xlsx` 均通过查看、查找、单格/矩阵写入、sheet、行和列操作往返测试。
- AI 可通过 stdout、stderr、JSON 和退出码准确判断结果。
- `view --json | write --stdin` 能在两种格式间回写值与公式文本。
- 输出能由 LibreOffice 重新打开，目标改变正确，未修改哨兵值保持不变。
- patch 任一操作失败时不发布；成功时只保存一次并在最终状态统一验证。
- Windows 用户级 CMD 启动器能够通过 LibreOffice 自带 Python 运行，中文输出、字体检查、
  打印机枚举抑制、UNO 连接、命令锁和临时 profile 清理均有真实验证。
